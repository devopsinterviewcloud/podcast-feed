# podcast-feed

RSS feed and audio for the DevOps & Cloud Interview Prep podcast, served via GitHub Pages.

- `feed.xml` is generated by `tools/make_feed.py` from `feed_config.json` + `episodes.json`. Don't edit it by hand.
- Episode audio lives in `audio/`, artwork in `art/`.
- To add an episode: drop the audio file in `audio/`, append an entry to `episodes.json`, run `python3 tools/make_feed.py`, commit and push.
